# 鲜花市场前端系统

基于 Vue 3 + Element Plus 的鲜花电商平台前端项目

## 技术栈

- **框架**: Vue 3.5.18 (Composition API)
- **UI组件库**: Element Plus 2.11.3
- **状态管理**: Pinia 3.0.3
- **路由**: Vue Router 4.5.1
- **HTTP客户端**: Axios 1.11.0
- **构建工具**: Vite 7.0.6
- **图标**: @element-plus/icons-vue 2.3.2

## 项目特点

- ✅ 三端分离：顾客端、商家端、管理员端
- ✅ 完整的用户认证和权限管理
- ✅ 购物车、订单、优惠券等电商核心功能
- ✅ 商品管理、产品溯源、评价系统
- ✅ 签到奖励、养护知识等特色功能
- ✅ 响应式设计，适配多种设备

## 快速开始

### 安装依赖

```sh
npm install
```

### 开发环境运行

```sh
npm run dev
```

访问 http://localhost:3000

### 生产环境构建

```sh
npm run build
```

## 环境配置

### 开发环境 (.env.development)
```
VITE_API_BASE_URL=http://localhost:18091
```

### 生产环境 (.env.production)
```
VITE_API_BASE_URL=http://your-production-server:18091
```

## 功能模块

### 顾客端
- 🏠 首页：商品展示、分类导航
- 🛍️ 商品：列表、详情、搜索、收藏、评价
- 🛒 购物车：商品管理、批量操作
- 📦 订单：下单、支付、物流追踪
- 🎟️ 优惠券：领取、使用
- ✅ 签到：每日签到、奖励积分
- 📚 养护知识：浏览、学习
- 👤 个人中心：信息管理、收货地址

### 商家端
- 📊 工作台：数据统计
- 📦 商品管理：发布、编辑、上下架
- 🔍 产品溯源：溯源信息管理
- 📋 订单管理：查看、发货
- 🎫 优惠券：创建、管理

### 管理员端
- 📊 管理后台：数据概览
- 🏢 商家管理：审核、冻结/解冻
- ⭐ 评价管理：审核评价
- 📦 订单管理：查看所有订单
- 📖 养护知识：发布、编辑
- ⚙️ 系统配置：系统参数管理

## 项目结构

```
src/
├── api/              # API接口封装
├── assets/           # 静态资源
├── components/       # 公共组件
├── router/           # 路由配置
├── stores/           # Pinia状态管理
├── utils/            # 工具函数
├── views/            # 页面组件
├── App.vue
└── main.js
```

## 注意事项

1. 后端API地址需要在环境变量中配置
2. 密码在后端使用MD5加密，前端无需处理
3. 支付功能为模拟实现
