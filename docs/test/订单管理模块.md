# Order Management Module

## Module Overview

The Order Management module governs the full lifecycle of an order from creation to completion or refund. Customers can create orders from their cart, choose a payment method, cancel unpaid orders, confirm receipt, and request refunds. Merchants fulfil orders by marking them as shipped. Administrators have visibility over all platform orders and handle refund audits. The order lifecycle follows a strict status workflow: PENDING_PAYMENT → PAID → SHIPPED → COMPLETED / CANCELLED / REFUND states.
