# Shopping Cart Module

## Module Overview

The Shopping Cart module allows logged-in customers to manage the items they intend to purchase. Core capabilities include viewing the cart, adding products, adjusting item quantities, removing individual items, clearing the entire cart, and batch-deleting selected items. The module integrates with product stock information to prevent invalid quantity updates and provides calculated subtotals for each line item.
