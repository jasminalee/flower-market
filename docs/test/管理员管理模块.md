# Administrator Management Module

## Module Overview

The Administrator Management module provides the platform administrator with oversight and control over all major entities in the system. Capabilities include viewing platform-level dashboard statistics, managing customer accounts and membership levels, auditing and managing merchant registrations, monitoring all platform orders, approving or rejecting product reviews, and maintaining the knowledge article library. This module is restricted exclusively to users with the ADMIN role.
