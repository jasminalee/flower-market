# Coupon Module

## Module Overview

The Coupon module supports promotional campaigns for both the platform administrator and individual merchants. Administrators and merchants can create discount coupons with specific amounts, expiry dates, and usage limits, then generate redeemable coupon codes. Customers can browse available coupons, claim them to their accounts, view their received coupons by status, and apply eligible coupons at checkout to reduce the order total.
