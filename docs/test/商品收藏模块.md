# Product Favorites Module

## Module Overview

The Product Favorites (wishlist) module allows logged-in customers to bookmark products they are interested in for future reference. Customers can add or remove products from their favorites list, view all favorited products in a paginated list, and check whether a specific product is currently in their favorites (used by the UI to toggle the favorite button state).
