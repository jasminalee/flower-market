# Check-In & Rewards Module

## Module Overview

The Check-In & Rewards module is a gamification feature that encourages daily customer engagement. Customers can perform one check-in per calendar day to earn reward points or credits. The module tracks consecutive check-in streaks, maintains a full history of past check-ins, and provides aggregated statistics including the current streak length, today's check-in status, and cumulative rewards earned.
