# User Authentication Module

## Module Overview

The User Authentication module handles all identity-related operations for the three roles in the system: **Customer**, **Merchant**, and **Administrator**. Core capabilities include account registration, login/logout, password management, and access control enforcement. This module is foundational — all other modules depend on it for identity and permission validation.
