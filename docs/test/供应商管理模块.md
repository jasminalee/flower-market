# Supplier Management Module

## Module Overview

The Supplier Management module allows platform administrators to maintain a registry of flower suppliers. Administrators can create and update supplier records with contact and status information, query the list with pagination and filtering, retrieve individual supplier details, delete outdated records, and toggle supplier active/inactive status. Active suppliers can be listed for use in dropdown selections within other modules.
