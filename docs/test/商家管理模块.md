# Merchant Management Module

## Module Overview

The Merchant Management module provides all operational capabilities for an approved merchant account. Merchants can manage their store profile and logo, access a sales dashboard with key metrics, manage their products, create and manage store-specific coupons, and process incoming orders (viewing and shipping). This module covers all functionality accessible within the merchant portal.
