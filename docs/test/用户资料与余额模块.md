# Customer Profile & Balance Module

## Module Overview

The Customer Profile & Balance module manages personal account information and the prepaid wallet for customers. Customers can view and update their personal details (name, phone, avatar). The integrated balance wallet allows customers to top up funds via third-party payment methods (Alipay, WeChat Pay) and use the balance for order payments. A full transaction history is available showing charges, deductions, and refunds.
