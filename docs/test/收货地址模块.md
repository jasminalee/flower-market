# Shipping Address Module

## Module Overview

The Shipping Address module allows customers to manage their delivery addresses. Customers can add multiple addresses, update or delete existing ones, and designate a default address that will be pre-selected at checkout. Each address stores recipient name, contact phone, full administrative region (province, city, district), and a detailed street address.
