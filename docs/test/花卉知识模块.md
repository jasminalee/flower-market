# Flower Care Knowledge Module

## Module Overview

The Flower Care Knowledge module is a content library that provides customers with articles about flower care, arrangement tips, and species information. Administrators manage the full content lifecycle: creating, editing, publishing, and deleting articles. Published articles are accessible to all users (including unauthenticated visitors) via a searchable, paginated list. Logged-in customers can post comments on articles, and all users can view approved comments.
