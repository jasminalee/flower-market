# Product Category Module

## Module Overview

The Product Category module enables administrators to organise the flower marketplace's product catalogue into a hierarchical category tree. Administrators can create top-level (parent) categories and nested subcategories, update existing category information, and delete categories. All users (including customers and merchants) can query the full category list for filtering and navigation purposes.
