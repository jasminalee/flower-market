# Product Management Module

## Module Overview

The Product Management module covers the full lifecycle of flower products on the platform. Merchants can create, update, delete, publish, and unpublish their products, including uploading main images and detail photos. Customers can browse products with rich filtering options (category, keyword, price range, merchant, sort order) and view detailed product pages. This module is central to the marketplace's core value proposition.
