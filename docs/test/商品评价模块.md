# Product Review Module

## Module Overview

The Product Review module allows customers who have completed an order to rate and review purchased products. Reviews consist of a star rating (1–5) and optional written text with image uploads. Submitted reviews enter a PENDING state and must be approved by an administrator before they become publicly visible on the product page.
