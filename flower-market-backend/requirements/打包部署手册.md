# 花卉商城项目部署手册

## 项目概述

花卉商城项目是一个前后端分离的电商系统，包含客户前台、商家后台和管理员后台三个子系统。项目采用Vue.js + Vite作为前端技术栈，Spring Boot作为后端技术栈。

## 环境准备

### 必备软件

- **Node.js** (版本 >= 20.19.0 或 >= 22.12.0)
- **Java JDK** (版本 1.8)
- **Maven** (3.6.0及以上)
- **MySQL** (8.0及以上)

### 环境检查命令

```bash
# 检查 Node.js 版本
node --version

# 检查 npm 版本
npm --version

# 检查 Java 版本
java -version

# 检查 Maven 版本
mvn -version

# 检查 MySQL 服务
mysql --version
```

## 部署步骤

### 1. 数据库配置

1. 确保 MySQL 服务正在运行
2. 修改后端配置文件 `src/main/resources/application.yml` 中的数据库连接信息（用户名、密码等）

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://127.0.0.1:3306/flower_market?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: your_username
    password: your_password
```

注意：首次启动会自动创建数据库和初始化数据。

### 2. 前端构建

1. 进入前端目录
   ```bash
   cd flower-market-frontend
   ```

2. 安装依赖
   ```bash
   npm install
   ```

3. 构建生产版本
   ```bash
   npm run build
   ```

4. 构建完成后，前端文件会输出到 `dist` 目录

### 3. 将前端构建结果集成到后端

1. 将前端 `dist` 目录下的所有文件复制到后端项目的 `src/main/resources/static` 目录
   ```bash
   # Windows 命令
   xcopy /E /I flower-market-frontend\dist src\main\resources\static
   
   # Linux/Mac 命令
   cp -r flower-market-frontend/dist/* src/main/resources/static/
   ```

### 4. 后端打包

1. 返回项目根目录
   ```bash
   cd ..
   ```

2. 使用 Maven 打包后端项目
   ```bash
   mvn clean package -DskipTests
   ```

3. 打包成功后，在 `target` 目录下会生成 `flower-market-backend-1.0.0-SNAPSHOT.jar` 文件

### 5. 启动应用

1. 直接运行 JAR 包
   ```bash
   java -jar target/flower-market-backend-1.0.0-SNAPSHOT.jar
   ```

2. 或者指定端口运行
   ```bash
   java -jar target/flower-market-backend-1.0.0-SNAPSHOT.jar --server.port=3000
   ```

## 部署配置详解

### 前后端整合原理

1. 前端通过 `vite build` 命令构建为静态资源
2. 构建后的文件放置在后端的 `src/main/resources/static` 目录下
3. 后端通过 `WebConfig.java` 配置静态资源映射

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Override
    public void addResourceHandlers(ResourceHandlerRegistry registry) {
        // 访问 / 开头的请求，都去 resources/static 目录找对应静态文件
        registry.addResourceHandler("/**")
                .addResourceLocations("classpath:/static/");
    }

    @Override
    public void addViewControllers(ViewControllerRegistry registry) {
        registry.addViewController("/").setViewName("forward:/index.html");
    }
}
```

这样，整个应用就可以通过一个端口对外提供服务，前端页面和后端API都在同一个域名下，避免了跨域问题。

- **应用主页**: http://localhost:3000
- **API文档**: http://localhost:3000/doc.html

## 常见问题及解决方案

### 1. 端口冲突
如果3000端口已被占用，可以在启动时指定其他端口：
```bash
java -jar target/flower-market-backend-1.0.0-SNAPSHOT.jar --server.port=8080
```

### 2. 数据库连接失败
- 检查 MySQL 服务是否运行
- 确认数据库用户名密码是否正确
- 确认数据库是否已创建

### 3. 前端页面无法加载
- 确认前端已正确构建
- 确认构建后的文件已放置在 `src/main/resources/static` 目录下
- 检查 `WebConfig` 静态资源配置是否正确

### 4. API 请求失败
- 确认前后端整合后，API 请求路径是否正确
- 前后端整合后，API 请求应直接使用相对路径，如 `/api/product/list`

## 一键部署脚本（可选）

您可以创建一个部署脚本来自动化以上步骤：

### Windows 批处理脚本 (deploy.bat)
```batch
@echo off

echo 正在构建前端...
cd flower-market-frontend
npm install
npm run build
cd ..

echo 正在清理旧的静态资源...
del /Q /S src\main\resources\static\*

echo 复制前端构建文件到后端静态资源目录...
xcopy /E /I flower-market-frontend\dist src\main\resources\static

echo 构建后端项目...
mvn clean package -DskipTests

echo 启动应用...
java -jar target\flower-market-backend-1.0.0-SNAPSHOT.jar --server.port=3000
```

### Linux/Mac Shell 脚本 (deploy.sh)
```bash
#!/bin/bash

echo "正在构建前端..."
cd flower-market-frontend
npm install
npm run build
cd ..

echo "清理旧的静态资源..."
rm -rf src/main/resources/static/*

echo "复制前端构建文件到后端静态资源目录..."
cp -r flower-market-frontend/dist/* src/main/resources/static/

echo "构建后端项目..."
mvn clean package -DskipTests

echo "启动应用..."
java -jar target/flower-market-backend-1.0.0-SNAPSHOT.jar --server.port=3000
```

## 项目维护

### 更新前端
1. 修改前端代码
2. 重新执行前端构建步骤
3. 重新复制文件到后端静态资源目录
4. 重新打包后端项目

### 更新后端
1. 修改后端代码
2. 重新打包后端项目
3. 重启应用

### 生产环境建议
- 在生产环境中关闭 Swagger 文档（设置 `knife4j.production=true`）
- 配置生产环境数据库连接
- 使用反向代理服务器（如 Nginx）来部署应用
- 设置适当的 JVM 参数以优化性能
