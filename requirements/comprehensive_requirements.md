# 鲜花电子商务平台详细需求说明书 (依据 Interim Report)

## 1. 项目背景与引言
### 1.1 项目背景
鲜花消费市场正从季节性购买转向日常消费，消费者对多元化选择、透明溯源、专业配送及养护指导提出了更高要求。传统中小型花店面临数字化转型压力，现有的综合电商平台缺乏针对花卉行业（如库存管理、专业养护、生命周期管理）的垂直功能。

### 1.2 项目目标
开发基于 SpringBoot + Vue.js 的垂直电子商务平台，助力花店数字化运营，优化消费者体验。核心目标包括：
*   **运营数字化**：实现订单、库存、供应商的全流程数字化管理。
*   **客户关系管理**：通过会员体系与积分激励提升复购率。
*   **知识赋能**：建立养护知识库，解决“易买难养”痛点。
*   **数据驱动**：提供仪表盘支持科学决策。

## 2. 角色与权限定义
| 角色名称 | 核心职责 |
| :--- | :--- |
| **顾客** | 浏览产品、搜索、下单、管理购物车、管理地址、查询订单、跟踪物流、申请售后、参与会员积分与签到、阅读养护知识。 |
| **商家** | 维护产品信息（SKU、专业属性）、库存监控与调拨、订单审核与发货、供应商管理、营销活动（优惠券）设置、数据统计查看。 |
| **管理员** | 用户权限与角色分配、系统参数配置、基础数据（分类、标签）维护、大规模数据监控、技术支持与系统安全保障。 |
| **系统自动/定时任务** | 自动执行库存低额预警、订单自动审核（按需）、状态同步、数据异地备份。 |

## 3. 详细功能需求

### 3.1 产品与供应管理
*   **数字化信息管理**：
    *   **基础属性**：SKU、价格、图片、多级分类（如：鲜切花 -> 玫瑰）。
    *   **专业属性**：**花期**、**维护难度**、**适宜环境**（温湿度、光照要求）、**花语**。
    *   **状态管理**：上架/下架/售罄状态。
*   **供应商管理**：
    *   维护供应商资质、合同、评分。
    *   管理采购订单与入库验收。
*   **可追溯性管理**：
    *   记录产地、种植基地、采摘时间、批次信息。
    *   前端展示溯源二维码或详情页。

### 3.2 智能库存管理
*   **实时监控**：多仓库实时库存查询，锁定库存（未支付订单预留）。
*   **智能预警**：设定安全库存阈值，自动发送低库存提醒。
*   **批次与效期**：针对鲜切花进行**保质期管理**与先进先出（FIFO）控制。
*   **运营支持**：入库、出库、调拨、盘点差异处理。

### 3.3 全流程订单管理
*   **订单生命周期**：待支付 -> 已支付 -> 准备中 -> 已发货 -> 配送中 -> 已完成。
*   **特殊配送支持**：支持**预约配送时间**（日期及特定时间段）。
*   **售后与投诉**：退款/换货申请、原因上传（如枯萎、损坏）、商家在线回复与满意度回访。
*   **物流追踪**：集成物流接口，实时展示配送位置与状态更新。

### 3.4 会员与精准营销
*   **会员生态**：
    *   **等级与成长值**：根据消费金额提升等级，享受差别权益。
    *   **积分系统**：下单奖励、签到获取、积分兑换商品或券。
*   **营销工具**：
    *   **优惠券**：固定金额券、百分比折扣券、满减券。
    *   **灵活促销**：捆绑销售（如花+瓶）、节日限时折扣。
*   **精准触达**：
    *   基于用户偏好标签（如：喜欢多肉）进行内容/产品推荐。
    *   **收藏功能**：降价提醒、到货通知。

### 3.5 知识库与内容运营
*   **养护百科**：分场景（居家、办公、礼赠）提供专业养护视频与文章。
*   **互动评价**：5星评分、多图/视频评价、商家互动回复。
*   **FAQ与智能问答**：常见配送、退款、养护问题自助查询。

### 3.6 数据分析视窗
*   **销售仪表盘**：销售额、订单量、客单价、转化率趋势。
*   **商品热力分析**：TOP销售产品榜单。
*   **库存周转分析**：资金占用情况与周转率报表。

## 4. 非功能性需求
### 4.1 性能要求
*   **响应速度**：页面首屏加载 ≤ 3s，交互操作 ≤ 2s。
*   **高并发**：支持 1,000 同时在线，500 并发交易处理。

### 4.2 安全与可靠性
*   **安全加密**：敏感数据 HTTPS 传输，密码 BCrypt 加密。
*   **权限控制**：基于角色的访问控制（RBAC）。
*   **高可用**：99.9% 正常运行，具备自动故障恢复能力。

### 4.3 兼容性
*   主流浏览器（Chrome, Safari, Edge, Firefox）及移动端（iOS/Android）适配。

---

## 5. 技术架构简述
*   **前端**：Vue.js + Element-UI + Vuex + Axios。
*   **后端**：Spring Boot + MyBatis-Plus + JWT + Spring Security。
*   **存储**：MySQL (关系型数据) + Redis (高速缓存/会话管理)。
*   **代理**：Nginx (负载均衡/静态资源服务)。
